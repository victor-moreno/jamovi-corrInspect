# corrInspect

A [jamovi](https://www.jamovi.org) module that clones jmv's **Correlation Matrix** analysis,
redesigned for cleaner output: a tidy one-row-per-pair table instead of an n-by-n matrix, an
inspector mode for comparing one reference variable against several others, annotated
scatterplots with the regression line drawn in place, and a colour-coded heatmap. All other
functionality (Pearson/Spearman/Kendall, significance flags, hypothesis direction) matches jmv.

Appears in jamovi's menu as **Regression > Correlation > Correlation Inspector**.

Built from scratch as an independent module, using jmv's Correlation Matrix as the starting point
for its options (`vars`, coefficient checkboxes, hypothesis direction, confidence interval) — see
below for what differs and why.

## What's different from jmv::corrMatrix (major changes)

### Tidy table instead of a matrix

jmv presents results as an n-by-n grid: every cell stacks r/df/p/CI as its own sub-rows, so even a
single pair of variables carries the full matrix scaffold (an empty diagonal cell, headers
repeated on both axes), and adding a confidence interval widens the table further. corrInspect
uses one row per (pair, coefficient) instead, with the 95% CI collapsed into a single
`[lower, upper]` cell rather than two columns. With exactly two variables this naturally reduces
to a single row — there's no separate "two-variable" mode, it's just what the tidy table looks
like for one pair.

### An inspector mode, no separate switch

jmv only compares all selected variables against each other. corrInspect adds a second mode:
compare one reference variable against a set of others — useful for inspecting candidate
predictors or confounders before a regression. There's no mode option to keep in sync: an empty
"Reference variable" box means all-vs-all; setting it switches to one-vs-the-rest automatically,
comparing it against the rest of "Variables".

### Confidence intervals for Spearman and Kendall

jmv (and base R's `cor.test`) only provides a confidence interval for Pearson's r. corrInspect
adds one for Spearman's rho and Kendall's tau-b too, via a Fisher z-transform with the Fieller,
Hartley & Pearson (1957) variance correction (`Var(z) = 0.437/(n-4)` in place of the `1/(n-3)`
that's exact for Pearson).

### Annotated scatterplots with the regression line

jmv's matrix plot is a static scatterplot grid (optionally with density diagonal and printed r
values), with no regression line. corrInspect draws the fitted line directly on the plot,
annotated in place with r, p, and the line's equation — each independently toggleable — plus
optional confidence (blue) and prediction (pink) bands. With more than two variables and no
reference variable, choose between a compact matrix layout (small panels, one per pair) or one
full-sized annotated scatterplot per pair.

### A colour-coded heatmap instead of a text matrix

jmv's matrix plot prints plain-text r values on the scatterplot grid's diagonal. corrInspect
replaces the all-vs-all overview with a colour-coded heatmap (or a single column, in reference
mode), with an independently selectable coefficient and a "Details" toggle that adds each cell's
CI/p/N/significance flag on top of r.

### Spanish and Catalan translations

Ship with the module (`corrInspect/jamovi/i18n/`), covering the panel, tables and plots.

## Installation (sideload)

Prebuilt `.jmo` files are attached to the [Releases](../../releases) page, one release per
jamovi/R version. Pick the file matching your OS and jamovi's bundled R version (check
**Help -> About** in jamovi), then in jamovi: **Modules -> jamovi library -> Sideload** and select
the downloaded `.jmo`.

## Repository layout

- `corrInspect/` — R package source (analysis definitions, R code, jamovi UI yaml, translations)
- `tools/` — build, install and release helper scripts
- `dist/` — packaged `.jmo` build output per R version/OS/arch, generated by
  `tools/prepare-jmo.sh`/`tools/release.sh` (not tracked in git; attached to releases)

## Building

```
bash tools/install.sh desktop   # builds corrInspect/corrInspect_<version>.jmo and installs it
                                 # into jamovi.app (macOS) using whichever R `Rscript` resolves to
bash tools/install.sh docker    # same, into a running `jamovi` Docker container (needs jmc)
bash tools/install.sh           # both, whichever are available
```

Then repackage for other jamovi/R versions and ship a release:

```
bash tools/prepare-jmo.sh 4.6.0 all     # metadata-only repackage into dist/
bash tools/release.sh 4.6.0             # + publish a GitHub release with those assets
```
